# 🌱 EcoMate

## Neighbourhood Waste and Recycling Coordination Platform

EcoMate is a mobile-based waste management and recycling coordination platform designed to connect community users, waste collectors, recycling centres, and municipal authorities through a single digital system.

The platform aims to improve waste collection coordination, community waste reporting, recycling activities, and municipal monitoring while encouraging cleaner and more sustainable communities.

---

## 🎯 Project Objectives

EcoMate aims to:

- Improve the coordination of scheduled waste collection.
- Allow users to request special waste pickups.
- Provide a centralized system for reporting waste-related issues.
- Help users correctly categorize and recycle waste.
- Connect community users with nearby recycling centres.
- Support waste collectors with assigned collection operations.
- Provide municipal authorities with monitoring and management capabilities.
- Improve communication between all stakeholders involved in waste management.

---


## 👥 Main Users

The EcoMate platform supports the following user roles:

- Community Users
- Waste Collectors
- Recycling Centre Officers
- Municipal Officers
